How this tool works

Read before starting a large transfer

  • It requests test data from speed.cloudflare.com over HTTPS and counts readable response-body bytes.
  • One download stream is used to make the byte target more predictable and reduce excess in-flight traffic.
  • Requests use small chunks; pause, resume and stop controls abort the current stream.
  • A 20-second stalled request is stopped automatically. Each session is capped at 1 GB.
  • No response data is saved to disk or uploaded to this website. Session history stays in local browser storage.
Important: Browser payload counters exclude HTTP headers, TLS overhead, retransmissions and other network traffic. Your mobile operator or ISP may report a different amount. Do not use this with a metered connection unless you accept the cost.
